# Supported image worker model

English | [中文](2026-10-02-image-worker-supported-model.zh.md)

The native image worker defaults to gpt-5.6-luna, present in the authenticated Codex model catalog. The previous gpt-6-luna default is rejected by the subscription endpoint before generation. Model availability belongs to the account catalog, not API documentation.

Terminal model rejection is reported distinctly from missing image output without forwarding raw provider diagnostics. Unknown operations remain subject to reconciliation.
