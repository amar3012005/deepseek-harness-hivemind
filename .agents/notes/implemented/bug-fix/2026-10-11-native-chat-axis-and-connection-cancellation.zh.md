# Agent Note: 原生聊天轴线与连接取消

Status: implemented

[English](2026-10-11-native-chat-axis-and-connection-cancellation.md) | 中文

## 问题

视口位移和员工专用消息宽度导致原生消息与输入框偏离。持久连接卡片没有取消回调，用户放弃请求后仍然显示。

## 决定

复用原生会话内容宽度和面板轴线。连接卡片保持紧凑，原因可展开，保留现有操作。现有连接应用工具新增 cancel_connection，要求精确的已保存工作流和请求调用标识。现有会话收据记录 cancelled；投影只移除该请求，继续操作拒绝已取消请求。不解除提供商账户连接。用户明确拒绝时 Runtime 关闭对应请求；仅切换话题则保持待处理。

## 考虑的替代方案

拒绝视口位移，因为预览和导航会改变原生面板布局。拒绝本地隐藏，因为刷新后会恢复。拒绝任意近期文本匹配，因为可能取消无关工作。

## 后果

完整记录仍然保存。用户重新明确请求时使用新工作流。取消不批准访问，不改变邮件投递收据，也不声称提供商操作成功。
