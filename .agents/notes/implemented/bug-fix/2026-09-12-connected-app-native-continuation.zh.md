# Agent Note: 原生已连接应用续接

Status: implemented

[English](2026-09-12-connected-app-native-continuation.md) | 中文

## Problem

Composio 搜索发现应用未连接后，会结束工具调用；浏览器按钮再发送一条合成用户消息来继续。这会开启新一轮对话，重复上下文和技能路由，并可能重新发现另一个提供商，而不是续接原来的 Composio 会话和计划。

## Decision

已连接应用桥通过现有 `userQuestions` 服务让原始搜索工具调用保持等待状态。它发布一个标准问题，包含两个普通答案选项，以及一个经验证、与具体应用无关的 HIVE 展示标记；该标记携带绑定会话的授权 URL。HIVE 客户端插件只从现有 Remote Event 瀑布流中接管带有该标记的请求，并在运行中的已连接工具行内渲染提供商卡片和恰好两个操作。常驻输入框继续挂载在对话记录下方。打开授权页面不会结束问题；请求继续时，系统使用原始会话 ID 调用 `COMPOSIO_WAIT_FOR_CONNECTIONS` 验证连接。只有明确的活跃状态证据才会把原始精简搜索结果、所选工具和执行契约交还给同一轮代理执行。

旧的 HIVE 浏览器回调不再通过新会话消息发送“我已连接……”。没有活动代理的无头调用方仍使用精简的已结束连接回执。

## Alternatives considered

**再发送一条用户消息。** 普通聊天记录可以持久化，但这会重新启动模型路由，让模型重建服务器已经拥有的工作流。

**替换常驻输入框。** 输入框链可以展示待处理交互，但会把授权控件与发起请求的工具分离，并在视觉上替换正常输入位置。已连接工具视图已经拥有正确的对话记录位置，并读取同一个 Session 待处理交互。

**从 HIVE UI 插件导入原生问题载体。** 客户端包纯度规则禁止跨插件运行时导入。因此，HIVE 插件使用公开的 Cordis Remote Event 和待处理交互服务；未修改的通用问题插件继续处理所有不带标记的请求。

**修改代理循环。** 现有循环已经支持等待人工交互，不需要增加 Composio 特殊分支。

## Consequences

连接授权无需额外模型步骤即可暂停推理，验证成功后也无需重新搜索即可续接原始 Composio 计划。内联控件紧邻运行中的工具证据，同时不会取代输入框。该标记和 UI 与提供商无关，而且两个标签都是普通问题选项，因此通用问题 UI 仍可兼容。原生 Harness 循环、问题包和渲染器均未修改。聚焦的主机与 HIVE 客户端测试覆盖展示验证、内联位置、非结算授权操作、同一瀑布流续接、会话复用、活跃状态验证和精简契约保留。

运行中的 runner 进程若中断，仍需要更广泛的持久工作流恢复契约；本决策消除了重复轮次，但本身不声称具备进程重启恢复能力。
