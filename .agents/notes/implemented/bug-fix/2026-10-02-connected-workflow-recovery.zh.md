# Agent Note: Connected workflow recovery

Status: implemented

[English](2026-10-02-connected-workflow-recovery.md) | 中文

## Problem

工具发现丢弃辅助工具，结果过滤隐藏资源标识，重试键包含新的调用标识。多步骤任务可能丢失报告并重复执行被中断的写操作。

## Decision

共享连接应用网关保留被选择的主要和关联工具，并从会话证据恢复工作流标识。执行结果按步骤投影并保留实际资源标识。检查点和写入意图使用现有会话收据事件，在发送前持久化。稳定操作标识复用已确认收据，待定写入必须核对外部状态。私有收据读取保留 Core 的字段、所有者和会话授权。

## Alternatives considered

**盲目重试被中断的写入。** 不采用，因为提供商可能已经发送邮件。

**公开全部原始收据。** 不采用，因为 MIME 载荷和私有提供商字段需要受限且受治理。

## Consequences

两种聊天模式共享恢复语义，无需修改代理循环。检查点是工作笔记，不是已验证完成。模型必须保存报告并依据证据继续，外部失败及私有收据过期仍需恢复。编译或容器健康不代表已经完成端到端发送验证。
