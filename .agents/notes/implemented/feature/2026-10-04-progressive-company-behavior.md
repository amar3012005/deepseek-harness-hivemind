# Agent Note: Progressive company behavior

Status: implemented

## Problem

Employee turn instructions requested complete reports and export offers while the employee persona required concise artifact replies to Runtime. Strategic guidance was available during awakening but ordinary agendas could bypass it. Persistent assignments did not explain how to use strategic, brand and method references in their saved descriptions.

## Decision

Both presets retain stable identity, authority and communication rules and provide short method-routing cues. The native skill registry supplies one shared company-strategy method on demand alongside the existing production and review methods. Direct questions remain direct; approved agendas need no special phrase. Runtime can own bounded work or delegate without duplicating an employee assignment. Employees reuse the Chief's saved task and plan, read supplied references and return concise saved results or actionable blockers. The existing dynamic turn instruction no longer requests unsolicited exports or a duplicated full artifact.

## Alternatives considered

A larger permanent persona would repeat methods on every turn. Another loader or company loop would duplicate native services. Neither is required: DSH skills expose summaries and load complete definitions through the existing registry. Source contracts were checked against MCP documentation revision 639ed015397290b3745d163aafe02ffee4aa3f84, particularly skills summaries and system prompt assembly.

## Consequences

No permission, native Teams task ownership, Schedule timing, Runtime acceptance, recall budget or history projection changes. Brand and strategy references use the existing task description rather than a new envelope schema. Focused tests cover native summary/loading, both profile cues, concise response guidance and assignment framing. Prompt budgets and pre-step latency require measurement before optimization. Source checks do not prove strategic quality, provider latency or business outcomes; a natural-agenda live evaluation remains required after release.
