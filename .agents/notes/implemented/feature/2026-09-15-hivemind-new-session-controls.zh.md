# Agent Note: HIVE new-session controls

Status: implemented

## Problem

原生 HIVE 编辑器只应在空白会话中显示范围和应用发现控件。此前 hero 连接器注册读取当前会话而不是 hero 会话，因此即使 hero 已渲染，建议也可能消失。

## Decision

HIVE 插件在原生 hero 行中渲染带文件夹图标、由服务器授权的范围选择器，并通过会话组件提供的 hero 会话渲染连接器建议。会话开始后 hero 消失，建议也随之消失。连接器搜索把经过认证的 HTTPS 标志保留到共享触发菜单，菜单用它替换通用引用图标。

## Alternatives considered

**保留编辑器级连接器停靠区。** 这会在活动会话中显示连接应用建议，不符合仅在新会话中显示的交互。

**在用户输入 `@` 前获取连接器目录。** 这会使应用发现变为预加载并暴露不可用的提供方元数据；现有的认证惰性搜索仍是搜索结果的权威来源。

## Consequences

原生空白会话组合现在只负责展示；项目授权仍由 runner 的项目端点负责，提供方和工具选择保持不变。共享触发候选项带有可选的仅展示标志字段，因此非连接器来源保留现有图标行为。

## Testing

聚焦组件测试覆盖文件夹控件、hero 连接器标志、HTTPS 连接器搜索标志和菜单标志渲染。发布前仍需要组装 GUI 和浏览器回放检查。
