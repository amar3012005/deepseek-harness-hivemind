# 经过身份验证的 Codex 提供方 API

[English](2026-10-08-codex-provider-api.md) | 中文

默认禁用的 HTTP 门面通过服务器拥有的一个账户提供文本、网络搜索、图像生成和原生实时语音。Cloudflare Worker 保存独立的公开接口密钥，并使用专用内部密钥转发请求。两个密钥均不暴露底层 Codex 授权。

每次调用都重新验证配置的公司和用户成员资格。图像请求解析拥有的原生会话，并使用现有的代理作用域 GenerationRegistry、持久操作标识和恢复状态。相同图像标识对应不同输入时拒绝请求。文本和搜索复用可刷新的 Codex 授权，不提供任意工具执行。实时语音保留原生会话、SDP 和通话生命周期协议，不是语音合成接口。

提供方通过托管运行器环境引用启用，不改变默认推理模型或前端。Worker 只接受固定 HTTPS 上游路由、有界 JSON 和 bearer 授权，不记录请求内容或秘密。文本和图像最多允许两个并发请求；断开连接会取消请求。

编译和 Worker 预构建已通过。生产启用与实际能力验证需要独立证据；源代码存在不代表提供方已上线。
