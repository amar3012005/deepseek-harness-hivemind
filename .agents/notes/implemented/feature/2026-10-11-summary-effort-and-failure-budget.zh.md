# Agent Note: 显式摘要推理档位与压力失败预算

Status: implemented

[English](2026-10-11-summary-effort-and-failure-budget.md) | 中文

## 问题

主请求可以选择低推理档位，但辅助摘要请求未指定档位而使用提供商默认值。失败摘要还可能在每个工具步骤重复。这两项问题均无需移除原生工具配对或保存的历史。

## 决策

原生摘要器接受显式档位并将其记录在摘要调用信息中。未显式配置时，仅继承相同提供商/模型的显式档位。公司预设独立于较旧会话请求头选择当前 Codex 路由。压力摘要失败后，每轮仅尝试一次；空闲状态、手动维护和已确认溢出恢复保留现有重试边界。

## 限制

首次提供商调用仍有提供商延迟。不删除历史，也不承诺功能完全不受影响。带签名的推理、未完成工具配对、Teams 消息、审批和原始事件继续由现有原生压缩管理；生成的摘要可能遗漏细节，因此原始证据仍可检索。

## 验证

定向测试覆盖档位路由、持久调用信息、空摘要拒绝、失败重试边界、原生配对、取消、冷恢复和公司预设组合。真实生产续接仍由发布负责人验证。
