# Persistent company Dreaming

One tenant conversation owns native parent/continuable-child identity, while each occurrence retains its own fenced execution receipt and checkpoint. The earliest stored pair is reused without rewriting completed history. Nightly Dreaming opens the native subagent address; Recent excludes subagent sessions.

Headless creation must mount the preset in the agent factory setup and pass explicit agentOptions. Cold children with an old descriptor receive current deployment model defaults through native installModelSelection on the child context. Failed model turns terminate an occurrence to prevent retry starvation; shutdown still leaves work recoverable. The host controller cancels its own reasoning because only the Dreamer child performs cognition.

References: docs/subsystems/subagent.md and packages/hivemind/dreamer/README.md.

Load the direct-parent child catalog before opening Dreaming; protect the URL while discovery is pending. Dreamer memory tools consume the provider through a child-scoped Cordis injection, including cold children. Native tests provide memory from a plugin fiber to cover production service resolution.
