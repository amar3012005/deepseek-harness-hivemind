# Agent Note: 经批准的 HIVE 资料更新

Status: implemented

[English](2026-09-21-approved-hive-profile-updates.md) | 中文

## 问题

聊天可以读取维护中的资料事实，但无法应用用户请求的更正。保存偏好称呼的记忆不会更新认证上下文所用的资料。

## 决策

记忆插件提供一个由提供方实现的可选资料设置工具。原生用户问题在批准前展示确切的描述性字段。运行时通过现有资料存储写入调用者范围内的事实，并使资料快照失效。预设区分资料更改与持久记忆保存。保存指令要求为明确命名的实体添加有依据的实体标签。

资料回执使用可忽略事件，因此不含插件的读取器仍可打开历史记录。取消不执行写入；已完成的调用重放其回执。Jev 的写入能力同时提供经批准的资料工具和记忆保存，不增加规划器。

## 考虑过的替代方案

**仅保存偏好记忆。** 这会让维护中的资料保持陈旧，无法满足明确的资料更正请求。

**修改账户或权限。** 请求需要的是描述性资料事实，而不是认证、所有权或访问角色变更。服务器仅接受六个维护中的资料字段。

## 影响

批准后的资料更改仅调用一次存储请求，不增加模型步骤。测试覆盖确切批准、取消、已完成调用重放、非法字段、传输和提供方失败。工具不保证多字段写入的原子性；提供方响应不完整时，重试前必须读取资料。
