# Agent Note: 原生 Codex 图像生成

Status: implemented

[English](2026-10-02-native-codex-image.md) | 中文

## Problem

原生图像生成尚未接入共享媒体注册表。仅附件输出和中断操作恢复需要持久化处理。

## Decision

两个预设只挂载一个共享渲染器。图像专用 Codex app-server 适配器通过仅主机事件读取受保护的 OAuth 凭据，消费原生图像回执并验证私有输出文件。执行前持久化会话意图。稳定操作标识复用已保存结果或核对已记录线程；未知结果停止生成。原始文件和预览使用原生附件存储。

## Alternatives considered

**计划共享 Responses 图像。** 此路径不支持图像生成，因此不采用。

**自动付费 API 回退。** 此行为会未经明确配置改变计费，因此不采用。

## Consequences

无需修改代理循环，也不向浏览器暴露凭据。现有网络搜索选择保持不变。原生任务不跨运行器重启存活；明确恢复使用持久操作状态。编译和运行器健康不能证明账号具备图像生成能力。
