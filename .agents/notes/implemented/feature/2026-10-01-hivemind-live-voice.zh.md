# Agent Note: 原生 HIVEMIND 实时语音

Status: implemented

[English](2026-10-01-hivemind-live-voice.md) | 中文

## 问题

输入框听写只会生成文字。实时公司大脑对话需要自然音频、经过身份认证的公司人格，以及现有受治理的工具。启动无关的 Codex 任务会分裂身份、回执和权限。

## 决策

HIVE 运行器挂载经过身份认证的 Cordis WebRTC 桥接。GPT-Live 处理语音与普通对话；客户端委派进入现有原生 Session。运行时通过 Agent 作用域事件提供精简资料。波形按钮拥有麦克风和连接生命周期，输入文字时仍使用现有发送操作。服务器 OAuth 凭证不会进入浏览器状态。

订阅适配器使用 Codex v3 协议和 `cove` 音色，限制房间、上下文、消息体和生命周期。上下文追加遵守传输层的 500 字节 UTF-8 上限。公司写入和连接器授权仍由原生工具处理；口头结果以持久化的 Agent 轮次结果为依据。

## 考虑过的替代方案

**用 Codex App Server 作为第二个任务运行时。** 它的自动后台 Agent 交接会重复现有 Harness Agent 及其授权路径。直接控制通道将任务委派给已经认证的 Session。

**听写加文字转语音。** 此方式集成更简单，但不具备用户要求的 GPT-Live 对话及打断行为。

## 影响

原生组合跨租户工作，无需逐租户配置插件。访问仍取决于已授权的订阅凭证和提供方可用性。实验性协议变更时需要实际传输检查。关闭语音会取消控制通道监听器，而已接受的原生任务仍可在原对话中恢复。

## 测试

定向输入框测试覆盖草稿切换、麦克风请求取消和清理。真实 Loader 测试组合覆盖原生服务激活、匿名和来源拒绝，以及 Session 接入前的租户作用域。隔离的订阅探测通过合成语音与测试结果确认音频和客户端委派传递；不读取或写入真实公司记忆。
