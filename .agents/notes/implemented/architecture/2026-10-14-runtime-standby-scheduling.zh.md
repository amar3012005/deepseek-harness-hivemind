# Runtime 待命运行器的调度

Runtime 与 Brain 可以使用独立运行器，同时保留现有的租户会话数据库。Web 运行器和 HQ 控制模块依赖原生 Schedule 服务，即使自动工作暂时停用也必须保留该服务。移除服务会阻止配置激活。将 PostgreSQL 提供程序替换为 JSON 存储域会使全局调度目录失去租户授权检查。

PostgreSQL 插件分别配置任务投递和任务管理，两者默认启用，保持现有部署行为。待命运行器同时关闭两者：不创建计时器或查询到期任务，直接投递调用不获取数据库连接，任务新增、更新及删除在写入前拒绝。已认证的读取继续执行成员资格检查和行级安全规则，保留原生记录。启用共享调度投递前必须建立持久的部署所有权。本修改不涉及代理循环或持久事件。

回归测试验证关闭投递时不访问数据库、默认唤醒行为保持不变，以及只读管理保留租户范围并拒绝修改 SQL。
