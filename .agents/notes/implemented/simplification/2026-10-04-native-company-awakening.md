# Native company awakening guidance

## Decision

Keep Runtime's five awakening outcomes as on-demand instructions rather than a per-step browsing workflow. The existing first-wake context now gives a short cue and saved checkpoints. The HQ preset mounts `runtime-company-awakening` through the existing skill registry; ordinary HyperAgent presets do not enable it.

## Native basis

DSH skills documentation at revision 639ed015397290b3745d163aafe02ffee4aa3f84 describes summary-only catalogs and full definitions retrieved by the native loader. The active checkout uses the same `skills.register` contribution and disposable scope pattern as submission review. Existing `hivemind_playbooks` search/load and research doctrine already provide research methods; no second playbook engine, agent loop, events or schema is introduced.

## Behavior

Use available company context and relevant private operating memory. If sufficient, avoid unnecessary public research. If incomplete, identify meaningful gaps, load an existing research method and inspect selected relevant sources. No exhaustive subpage crawl, mandatory screenshot quota, fixed assignment count or arbitrary timing. Preserve Runtime identity, existing tasks, evidence checks, approval boundaries, human narration and sleep handoff.

## Limits

Instructions guide model judgment rather than guarantee it. Native skills load only when requested by the model. Checkpoint receipt validation and wake admission are unchanged. Live awakening and visual evidence selection remain to be verified; unit checks do not prove strategic quality.
