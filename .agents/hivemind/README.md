# SINGULANCE HIVE-MIND entrypoint

Use this folder before changing a HIVE-MIND or HyperAgents Cordis profile,
plugin, runner UI, or runner artifact. Read `CONTRACT.json`, fetch the pinned
canonical contract, and select one owner in `ROUTING.json`.

The canonical task contract bounds lower-tier execution. This repository's
native Cordis architecture and package rules remain authoritative where more
specific. Do not copy platform instructions into new agent directories.
