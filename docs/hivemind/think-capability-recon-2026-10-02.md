Think tool contracts are not installed by copying prose. Provider-specific browser/search/Composio instructions were replaced with native discovery and registered schemas. Missing local skill aliases resolve to available action guidance. Existing catalog IDs and native skill provider precedence remain intact. Limitations: a website can block embedding; its original link remains available. Catalog guidance does not promise every task succeeds. Native provider failures, approval outcomes and evidence gaps remain explicit. PDFKit and Cloudflare Browser Rendering are different rendering engines; this upgrade preserves the working native PDF pipeline, not byte-for-byte PDF parity.
