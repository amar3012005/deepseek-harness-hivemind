# HQ company workspace

React components contributed through native Cordis slots provide a shared human/agent week calendar, execution agenda, task drawer, retained wake receipts and human planning forms. The original conversation, session rail, streaming and artifact surfaces remain their owning plugins.

The `hivemindHq` generated Remote resolves the authenticated HQ root. Its workspace projects native Team task revisions, dependencies, owners, artifact links and transition times alongside native Schedule wakes. Delivered occurrences are inbox receipts, never evidence of completed execution. Human planning and source/decision entries use compare-and-set durable events, without becoming a competing task engine. Assignment windows are distinct from deadlines and can be changed only before execution.

The autonomy switch appears both in the existing HQ conversation header and company workspace. Transport uncertainty disables mutation until refresh; stale revisions reconcile committed state. Models cannot enable autonomy. Native subscriptions refresh the view without model polling.

The native browser fixture verifies the built UI and PostgreSQL planning records. It does not prove cross-member sharing or a production autonomous company research loop. Those require separate acceptance and release evidence.
