# @deepseek-ai/dsh-hivemind-memory

[English](README.md) | 中文

提供渐进式 `hivemind_meta` 读取和需要批准的记忆保存。提供方还可以通过 `hivemind_update_profile` 更新调用者的描述性资料事实。租户范围仍由服务器确定。召回支持来源、项目、时间、标签、媒体类型、文件名和实体筛选，不接受租户标识符。

工具注册由插件 fiber 通过 Cordis effect 管理。重新加载或释放 HIVE 插件会移除其工具，不会在其他配置中留下重复或陈旧的注册。

## 模型体验

- **可见工具：**紧凑的元工具、记忆保存，以及可选的资料更新。
- **提示词成本：**有界 schema；证据仅在调用后出现。
- **KV-cache 影响：**稳定的工具 schema。

## 召回筛选

`recall` 始终要求聚焦的 `query`。仅当请求提供相关约束时，才使用 `source_platforms`、`project`、时间字段、`sort` 或 `tags`。`media_kind`、`filename` 和 `entities` 是用于内部媒体发现的便捷输入；工具会将其转换为服务器的 `kind:*`、`filename:*` 和 `entity:*` 标签。召回结果是证据元数据，而非本地文件系统路径或可获取的二进制产物。

## 已知限制与暂缓工作

资料更新在写入前通过原生用户问题展示确切字段。取消会保持资料不变。已完成的回执可以重放；不含此插件的读取器可以忽略资料审计事件。描述性的角色和公司字段不会改变访问权限或登录凭据。

超出初始有界结果的渐进式召回分页尚未实现。
