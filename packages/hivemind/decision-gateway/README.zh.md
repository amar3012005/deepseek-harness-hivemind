# HIVE-MIND 决策网关

[English](README.md) | 中文

该 Cordis 插件在一轮对话的第一个模型请求之前使用 Core 的有界决策合同。在 active 模式中，它把继承的工具表面缩小到所选的 HIVE 网关或连接应用网关。它不会规划、生成工具参数、授权或执行工作。

任何超时、传输故障、无效响应、Core 的低置信度 defer 或所选工具不可用，都会在同一轮中保留现有 Harness 工具表面。shadow 模式记录决策但不改变工具。off 模式不执行任何工作。

在继续步骤或下一轮开始之前，该限制会被解除，因此当前 Harness 选择器仍是 fallback，并负责所有后续进展。

## 模型体验

- **可见工具：** 不添加新工具；active 模式把第一个请求缩小到一个现有网关工具，或在直接回答时不提供工具。
- **提示词成本：** 不添加提示文本；普通 request header 会记录所选工具表面。
- **KV-cache 影响：** 稳定的系统前缀不变。

## 已知限制和延期工作

此版本只缩小第一个已接纳的用户消息。继续步骤会有意返回当前 Harness 选择器，直到按阶段工作的 Composio 和 HIVE-meta 消费方采用相同 Core 合同。

不发布 runtime invariant companion；该插件不拥有授权或执行状态，其临时作用域限制由专门的生命周期测试覆盖，而 request header 仍是模型表面的权威记录。
