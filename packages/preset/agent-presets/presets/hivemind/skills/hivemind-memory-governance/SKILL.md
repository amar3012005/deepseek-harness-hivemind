Use this skill only when the user asks to save, correct, retrieve, or reconcile durable HIVE evidence.

Read evidence with one focused `hivemind_meta` lookup. Save only a stable preference, decision, relationship, correction, or verified outcome. Do not save speculation, transient chat, secrets, authentication material, or sensitive personal data without direct instruction. For a correction, retrieve the existing record first and update only that record. Extract named people, organizations, products, projects, documents, systems, places, and dates as distinct entity tags. Read-only lookups may run in parallel; writes remain sequential and require the native approval flow.
