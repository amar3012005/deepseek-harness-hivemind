---
name: hivemind-artifact-delivery
description: Produce a user-requested document, HTML artifact, PDF, preview, or image through the native HIVE renderer.
---

Use this skill only when the user requests a durable artifact or visual deliverable. Complete the requested content before invoking the renderer. Use the native HIVE artifact renderer and preserve its tenant ownership, attachment, preview, and media limits. For PDFs, render finished Markdown and inspect the produced preview before reporting completion. Never claim an artifact was created until its saved receipt is available.
